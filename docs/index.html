Why not accuracy…

One pipeline, with no leakage between train and test

Upload a CSV or a ZIP of images. The agent profiles the data, looks up guidance, resamples the training rows, and reports metrics that hold up.

Split first

A stratified split comes before any scaling or resampling. The scaler is fitted on training rows only, and the test set is never resampled.

Agentic routing

The state machine reads imbalance, noise and dimensions, then picks SMOTE, ADASYN, Borderline-SMOTE or SMOTE-Tomek. Failed runs retry with safer settings.

RAG-guided settings

Qdrant returns k_neighbors, target ratios and compliance limits from stored papers and guidelines, with citations in every response.

Honest metrics

Precision, recall, F1 and PR-AUC. Accuracy is never computed. The decision threshold is tuned on validation data by default.

POST /ingestUpload a CSV or an image ZIP. Returns a dataset_id and the data profile.
POST /resampleRoute, retrieve guidance and resample the training partition.
POST /trainFit a classifier on the resampled rows, with self-healing retries.
POST /evaluateScore the untouched test set with an optimized threshold.

Architecture at a glance

One FastAPI service orchestrates an agent graph. Qdrant supplies guidance, an LLM router powers the assistant, and every run ends in a model card.

Built to be deployed, not just demoed

The same service the playground imitates, with the controls a team expects.

Self-healing

A failed resampler retries with a smaller k, then plain SMOTE, then random oversampling. Every retry is logged in the response.

Strategy benchmark

/compare scores every resampler on validation data and names the best one, so the choice is measured.

Model card

/report returns a Markdown summary: strategy, citations, threshold source and the leakage controls applied.

Hardened by default

Optional API key, CORS allow-list, upload and session limits, a non-root multi-stage image, health checks and CI tests.
